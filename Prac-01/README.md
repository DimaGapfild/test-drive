# Prac-01

Calculates the area of a square with side 6.

## Files

- `index.js`: the `squareArea(side)` function. Running the file prints the area for side 6.
- `test-index.test.js`: a test that checks `squareArea(6)` returns `36`.

## Usage

Requires Node.js 20 or later. No dependencies to install.

```bash
node index.js
# Area of a square with side 6: 36
```

## Running the tests

The tests use Node's built-in test runner:

```bash
node --test
```
